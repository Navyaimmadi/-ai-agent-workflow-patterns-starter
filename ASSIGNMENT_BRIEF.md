# Assignment Brief

## Module 1 Lab: Build Five Agent Workflow Patterns

The attached course brief requires five foundational AI workflow patterns to be implemented from scratch with the [AI SDK](https://ai-sdk.dev/docs/introduction), directly against an LLM API and without an agent framework.

## Required patterns

1. **Prompt Chaining** - the output of one prompt becomes the input to the next prompt.
2. **Routing** - a request is classified and sent to a suitable workflow, tool, or model.
3. **Parallelization** - independent tasks run at the same time and their results are combined.
4. **Orchestrator-Worker** - an orchestrator creates/delegates subtasks and merges worker results.
5. **Evaluator-Optimizer** - an evaluator scores a draft and the draft is improved in a feedback loop until the target quality or a safety limit is reached.

## Required deliverables

- Source code for all five implementations
- Documentation explaining each pattern
- Screenshots or execution logs showing successful runs
- A short reflection on real challenges and lessons learned

## Submission

Submit only the URL of the public GitHub repository containing the completed work.
